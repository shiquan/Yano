## Overview

**Yano** is an R package for spatial dissimilarity analysis（空间不相似算法）in single-cell transcriptomics. It detects features — such as genes, exons, junctions, or genetic variants — whose spatial expression patterns differ from a reference (e.g., the host gene or an alternative assay). The method works on any spatial embedding: PCA, UMAP, spatial coordinates, lineage trajectories, or integration spaces like Harmony.

### Key capabilities

- **Alternative splicing detection**: compare exon and junction expression against their host genes to identify differential isoform usage across cell populations.
- **Allele-specific expression**: test whether maternal and paternal alleles show divergent spatial patterns.
- **Variant annotation and prioritization**: annotate genetic variants with single-cell expression context and prioritize candidates using spatial statistics.
- **Multi-sample Visium analysis**: perform splicing-aware analyses across multiple spatial transcriptomics samples.
- **Interactive cell selection**: select cells from reduced-dimension plots or spatial coordinates using lasso and concave-hull tools.
- **Track visualization**: generate publication-ready coverage and transcript tracks with cross-panel highlighting, junction arcs, and multi-group support.

### How it works

Yano's core is the **spatial dissimilarity test**: for each feature, it computes a spatial autocorrelation statistic and compares it against a null distribution generated by permutation. Features whose spatial pattern deviates significantly from the binding feature are reported. The method does **not** depend on clustering or differential expression — it operates directly on the cell-by-cell spatial neighborhood graph, making it sensitive to subtle, spatially coherent signals even for lowly expressed features.
